# Agency OS: UI/UX principles to apply

Collected from the founder's references. Every screen of the Agency OS app must follow these.

## Goal

Reduce mental effort, get users to value fast (activation), keep churn low.

## Core UX (workflow and usability)

- **Reduce cognitive load.** Simple, functional layouts. Don't cram every feature onto one screen; users should spend time on their goal, not on learning the tool.
- **Onboard for fast activation.** Reach the "aha" moment quickly: action checklists, progress bars, contextual tooltips. No long multi-step tutorial.
- **Design for mental models and roles.** Navigation and dashboards follow how each role works (agency owner, PM, designer, developer, client), not the database.
- **Progressive disclosure.** Core features first; advanced settings, bulk actions and complex configuration appear as the user goes deeper.
- **No dead waiting states.** Long tasks (AI generation, exports) show status messages that say what is happening, not a bare spinner.
- **Feedback and guidance.** Clear success, error and empty states; inline help where people get stuck.
- **Accessible.** WCAG AA contrast, keyboard use, focus states, screen-reader labels, touch targets.
- **Efficient.** Shortcuts, bulk actions and defaults for frequent work.

## Core UI (visuals and architecture)

- **Visual consistency.** One type scale, colour set, button style and icon set everywhere.
- **Clear hierarchy.** Size, contrast and spacing make the primary action (Save, Create) obvious; secondary data recedes.
- **Scalable navigation.** Predictable, collapsible sidebar for main sections; command palette (Cmd/Ctrl+K) as the product grows.
- **Purposeful data tables.** Show the 5 columns people need by default; let power users add, hide and save views.
- **Lightweight design system at first.** Core colours, type scale, inputs, buttons, loaders. Grow it later.
- **Premium icons** support headings wherever they help (one icon family only).
- **Responsive** from day one; mobile is a first-class view.
- **Trust.** Social proof, clear pricing, security cues.

## The seven principles (summary)

User-centred · Simple · Consistent · Efficient · Feedback and guidance · Accessible · Scalable

## Measure success with

Retention, conversion, task completion rate, time on task, user error rate, NPS, CSAT, bounce and churn, heatmaps and click tracking, usability tests.
